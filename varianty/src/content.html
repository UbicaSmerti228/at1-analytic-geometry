С нуля · 20 минут

Минимум, без которого никак

Эти 9 фактов нужны почти в каждой задаче. Прочитай и попробуй пересказать своими словами.

1Вектор по двум точкам

«Конец минус начало»:

$$\overline{AB} = (x_B - x_A;\ y_B - y_A;\ z_B - z_A)$$

Пример: $A(2;5;1)$, $B(3;2;1)$ → $\overline{AB} = (1;-3;0)$.

2Середина отрезка

$$\left(\frac{x_A + x_B}{2};\ \frac{y_A + y_B}{2}\right)$$

Пример: $A(-3;2)$, $B(1;4)$ → середина $(-1;3)$.

3Скалярное произведение

$$\vec a\cdot\vec b = x_1x_2 + y_1y_2 + z_1z_2$$

Равно нулю ⇔ векторы перпендикулярны. Длина $|\vec a| = \sqrt{x^2 + y^2 + z^2}$. Угол:

$$\cos\varphi = \frac{|\vec a\cdot\vec b|}{|\vec a|\,|\vec b|}$$

4Коэффициенты = нормаль

В уравнениях $Ax + By + C = 0$ (прямая) и $Ax + By + Cz + D = 0$ (плоскость) вектор из коэффициентов $\vec n = (A;B;C)$ перпендикулярен прямой или плоскости.

Пример: $5x + y - 3z - 3 = 0$ → $\vec n = (5;1;-3)$.

5Знаменатели = направление

$$\frac{x - x_0}{m} = \frac{y - y_0}{n} = \frac{z - z_0}{p}$$

$\vec s = (m;n;p)$ идёт вдоль прямой. Точка $(x_0;y_0;z_0)$ — числа из числителей с обратным знаком: в $\frac{x+2}{3}$ стоит $x_0 = -2$.

6Угловой коэффициент

$$y = kx + b,\qquad k = \operatorname{tg}\alpha$$

$\alpha$ — угол между прямой и осью $Ox$, $b$ — где прямая пересекает $Oy$.

7Полный квадрат

$$x^2 + bx = \left(x + \frac b2\right)^2 - \frac{b^2}{4}$$

Пример: $x^2 - 6x = (x-3)^2 - 9$; $\ x^2 + 4x = (x+2)^2 - 4$.

8Эллипс и гипербола

Эллипс: $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$, $\ c^2 = a^2 - b^2$.

Гипербола: $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$, $\ c^2 = a^2 + b^2$.

Фокусы $(\pm c;0)$, эксцентриситет $e = \frac ca$. Оси $2a$ и $2b$ — значит, полуоси $a$ и $b$.

9Векторное произведение

Даёт вектор, перпендикулярный двум данным:

$$\vec a\times\vec b = \begin{vmatrix} \vec i & \vec j & \vec k \\ x_1 & y_1 & z_1 \\ x_2 & y_2 & z_2 \end{vmatrix}$$

$= \vec i\,(y_1z_2 - z_1y_2) - \vec j\,(x_1z_2 - z_1x_2) + \vec k\,(x_1y_2 - y_1x_2)$. Не забудь минус у $\vec j$. Проверка: результат скалярно на каждый вектор даёт 0.

Прямая на плоскости

№1 Короткий вопрос про прямую 2 б.

Что нужно знать
  • $k = \operatorname{tg}\alpha$ — угол с положительным направлением $Ox$, от $0^\circ$ до $180^\circ$.
  • В $Ax + By + C = 0$: если $A = 0$, прямая горизонтальна ($\parallel Ox$, $\perp Oy$); если $B = 0$, вертикальна ($\parallel Oy$, $\perp Ox$).
  • Прямая через две точки: $\dfrac{x - x_1}{x_2 - x_1} = \dfrac{y - y_1}{y_2 - y_1}$, затем «крест-накрест».
Вар. IIКакой угол образует прямая $y = -x + 1$ с положительным направлением оси $Ox$?
Решение

Угловой коэффициент $k = -1$, и $k = \operatorname{tg}\alpha$. Значит, $\operatorname{tg}\alpha = -1$.

Угол с осью берут от $0^\circ$ до $180^\circ$, а тангенс отрицательный — угол тупой: $\alpha = 180^\circ - 45^\circ = 135^\circ$.

α = 135° (3π/4)

Вар. IVПри каком значении $n$ прямая $4x + ny - 1 = 0$ перпендикулярна оси $Oy$?
Сначала реши сам · открыть решение

Прямая, перпендикулярная оси $Oy$, — горизонтальная ($y = \text{const}$). Для этого коэффициент при $x$ должен быть нулём. А он равен $4$, поэтому при буквальном прочтении такого $n$ нет.

Скорее всего, составитель ждёт $n = 0$: тогда уравнение $4x - 1 = 0$, то есть $x = \frac14$ — вертикальная прямая. Она перпендикулярна оси $Ox$ (и параллельна $Oy$), а её нормаль $(4;0)$ перпендикулярна оси $Oy$.

На АТ напиши оба вывода: «⊥ Oy невозможно, т.к. A = 4 ≠ 0; при n = 0 прямая x = 1/4 ∥ Oy». Так ты покажешь, что понимаешь условие при любом прочтении.

n = 0 (прямая x = 1/4); строго ⊥ Oy — ни при каком n

Кривые второго порядка

№2 Гипербола или эллипс по числам 2 б.

Метод
  1. Определи кривую: между квадратами плюс — эллипс, минус — гипербола.
  2. Найди $a$ и $b$. Если дано «ось $2a = 16$» — дели на 2.
  3. Связь с фокусом: эллипс $c^2 = a^2 - b^2$, гипербола $c^2 = a^2 + b^2$; эксцентриситет $e = \frac ca$, отсюда $c = e\cdot a$.
  4. Фокусы на оси абсцисс симметрично — это $F(\pm c;\,0)$ и уравнение вида $\frac{x^2}{a^2} \pm \frac{y^2}{b^2} = 1$.

Решение
1
$2a = 16 \Rightarrow a = 8$.
2
$c = \varepsilon a = \frac54\cdot 8 = 10$.
3
Гипербола: $b^2 = c^2 - a^2 = 100 - 64 = 36$.
x²/64 − y²/36 = 1

Плоскость

№3 Вопрос про плоскость 2 б.

Что нужно знать
  • У плоскости $Ax + By + Cz + D = 0$ нормаль $\vec n = (A;B;C)$.
  • Плоскости перпендикулярны ⇔ $\vec n_1\cdot\vec n_2 = A_1A_2 + B_1B_2 + C_1C_2 = 0$.
  • Плоскости параллельны ⇔ нормали пропорциональны.
  • Координатные плоскости: $Oxy$ — это $z = 0$, $Oxz$ — это $y = 0$, $Oyz$ — это $x = 0$.
  • Плоскость через точку $M_0$ с нормалью $\vec n$: $A(x - x_0) + B(y - y_0) + C(z - z_0) = 0$.
Вар. IIIПри каком значении $A$ плоскости $5x + y - 3z - 3 = 0$ и $2x + Ay + 3z + 1 = 0$ перпендикулярны?
Решение

$\vec n_1 = (5;1;-3)$, $\vec n_2 = (2;A;3)$. Перпендикулярность: $\vec n_1\cdot\vec n_2 = 0$:

$$5\cdot2 + 1\cdot A + (-3)\cdot3 = 0\ \Rightarrow\ 10 + A - 9 = 0\ \Rightarrow\ A = -1$$
A = −1
Вар. IVВ каком случае плоскость $Ax + By + Cz + D = 0$ параллельна плоскости $Oxz$?
Сначала реши сам · открыть решение

Плоскость $Oxz$ — это $y = 0$, её нормаль $(0;1;0)$. Параллельная плоскость имеет пропорциональную нормаль: $(A;B;C) \parallel (0;1;0)$, то есть $A = 0$, $C = 0$, $B \ne 0$.

Уравнение становится $By + D = 0$, то есть $y = -\frac DB$. При $D = 0$ плоскость совпадёт с $Oxz$, поэтому для параллельности нужно ещё $D \ne 0$.

A = 0 и C = 0 (B ≠ 0, D ≠ 0): плоскость y = −D/B
Вар. IIНаписать уравнение плоскости, точки которой одинаково удалены от точек $P(1;2;-3)$ и $Q(3;4;-1)$.
Сначала реши сам · открыть решение

Такая плоскость проходит через середину отрезка $PQ$ перпендикулярно ему.

1
Середина: $M\left(\frac{1+3}{2};\ \frac{2+4}{2};\ \frac{-3-1}{2}\right) = M(2;3;-2)$.
2
Нормаль: $\overline{PQ} = (2;2;2)$, можно взять короче $\vec n = (1;1;1)$.
3
$1(x - 2) + 1(y - 3) + 1(z + 2) = 0 \Rightarrow x + y + z - 3 = 0$.

Проверка: точка $(3;0;0)$ лежит в плоскости; до $P$: $4+4+9 = 17$, до $Q$: $0+16+1 = 17$ (квадраты расстояний равны).

x + y + z − 3 = 0

Прямая в пространстве

№4 Уравнение прямой в пространстве 2 б.

Метод
  • Нужны точка $(x_0;y_0;z_0)$ и направляющий вектор $\vec s = (m;n;p)$.
  • Каноническое: $\dfrac{x - x_0}{m} = \dfrac{y - y_0}{n} = \dfrac{z - z_0}{p}$. Параметрическое: $x = x_0 + mt$, $y = y_0 + nt$, $z = z_0 + pt$.
  • Через две точки: $\vec s = \overline{AB}$. Параллельная прямая — тот же $\vec s$.
  • Ноль в знаменателе — не ошибка: он значит, что эта координата не меняется.
Вар. IVСоставить канонические уравнения прямой, проходящей через точки $A(2;5;1)$ и $B(3;2;1)$.
Решение
1
$\vec s = \overline{AB} = (3 - 2;\ 2 - 5;\ 1 - 1) = (1;\,-3;\,0)$.
2
Точка $A$: $$\frac{x - 2}{1} = \frac{y - 5}{-3} = \frac{z - 1}{0}$$

Ноль под $z$ значит $z - 1 = 0$: вся прямая лежит в плоскости $z = 1$.

(x − 2)/1 = (y − 5)/(−3) = (z − 1)/0
Вар. IIIСоставить параметрические уравнения прямой, проходящей через начало координат параллельно прямой $\frac{x-2}{2} = \frac{y+5}{3} = \frac{z-1}{1}$.

Параллельные прямые имеют один направляющий вектор — знаменатели: $\vec s = (2;3;1)$. Точка — $O(0;0;0)$.

Вар. IIОпределить значения параметров $m$, $n$, $p$, при которых прямая $\frac{x - x_0}{m} = \frac{y - y_0}{n} = \frac{z - z_0}{p}$ параллельна оси $Ox$.
Сначала реши сам · открыть решение

Прямая $\parallel Ox$ ⇔ её направляющий $\vec s = (m;n;p)$ коллинеарен орту оси $\vec i = (1;0;0)$. Значит, $n = 0$, $p = 0$, а $m$ — любое, кроме нуля.

Тогда $y = y_0$ и $z = z_0$ постоянны, меняется только $x$.

Плоскость через точку

№5 Плоскость через точку и прямую 2 б.

Метод
  • Плоскость ⊥ прямой: направляющий прямой и есть нормаль плоскости, $\vec n = \vec s$ (знаменатели). Дальше $A(x - x_0) + B(y - y_0) + C(z - z_0) = 0$.
  • Плоскость через точку $P$ и прямую: в плоскости лежат два вектора — $\vec s$ прямой и вектор от $P$ до точки прямой. Уравнение — определитель из трёх строк равен нулю (как плоскость через три точки).

Плоскость, уровень B

№6 Прямые и треугольник на плоскости 4 б.

Что нужно знать
  • Угол между прямыми через угловые коэффициенты: $\operatorname{tg}\varphi = \left|\dfrac{k_2 - k_1}{1 + k_1k_2}\right|$.
  • Прямая через точку с коэффициентом $k$: $y - y_0 = k(x - x_0)$.
  • Медиана идёт из вершины в середину противоположной стороны.
  • Точка пересечения медиан $O$ — среднее арифметическое вершин: $x_O = \frac{x_A + x_B + x_C}{3}$, $y_O = \frac{y_A + y_B + y_C}{3}$.
  • Угол между векторами: $\cos\varphi = \frac{|\vec a\cdot\vec b|}{|\vec a|\,|\vec b|}$.

Решение

Точка пересечения медиан — среднее арифметическое вершин:

$$3 = \frac{2 + 3 + x_C}{3},\qquad 1 = \frac{2 + 0 + y_C}{3}$$

$x_C = 9 - 5 = 4$, $\ y_C = 3 - 2 = 1$.

Проверка: $\frac{2+3+4}{3} = 3$, $\frac{2+0+1}{3} = 1$.

Вар. IIВывод уравнения прямой на плоскости, заданной точкой и направляющим вектором.
Ответ

Дано: точка $M_0(x_0;y_0)$ и ненулевой вектор $\vec s = (m;n)$, параллельный прямой (направляющий вектор).

{{fig:q2|M лежит на прямой ⇔ M₀M ∥ s}}

Идея: возьмём произвольную точку $M(x;y)$ прямой. Вектор $\overline{M_0M}$ лежит на прямой, поэтому он коллинеарен $\vec s$.

Вывод: $\overline{M_0M} = (x - x_0;\ y - y_0)$. У коллинеарных векторов координаты пропорциональны:

$$\frac{x - x_0}{m} = \frac{y - y_0}{n}$$

Обозначив общее значение отношений через $t$, получим параметрические уравнения: $x = x_0 + mt$, $y = y_0 + nt$, $t \in \mathbb R$.

Пример: $M_0(1;2)$, $\vec s = (3;1)$: $\frac{x - 1}{3} = \frac{y - 2}{1}$, то есть $x - 3y + 5 = 0$.

Вар. IVВывод уравнения прямой с угловым коэффициентом и точкой.

Дано: точка $M_0(x_0;y_0)$ и угловой коэффициент $k = \operatorname{tg}\alpha$, где $\alpha$ — угол наклона прямой к положительному направлению оси $Ox$.

{{fig:q4|Угол при M₀ равен α (как соответственные углы при параллельных прямых)}}

Идея: возьмём на прямой другую точку $M(x;y)$ и построим прямоугольный треугольник с катетами $x - x_0$ (по горизонтали) и $y - y_0$ (по вертикали). Угол при вершине $M_0$ равен $\alpha$.

Вывод: тангенс — отношение противолежащего катета к прилежащему:

$$\operatorname{tg}\alpha = \frac{y - y_0}{x - x_0}\ \Rightarrow\ k = \frac{y - y_0}{x - x_0}$$
$$y - y_0 = k(x - x_0)$$

Частный случай: если $M_0 = (0;b)$ — точка на оси $Oy$, получаем $y = kx + b$. Вертикальная прямая ($\alpha = 90^\circ$) углового коэффициента не имеет.

Пример: $M_0(1;3)$, $k = 2$: $y - 3 = 2(x - 1)$, то есть $y = 2x + 1$.

Вар. V?Вопрос 5. Исследование общего уравнения прямой при различных значениях $A$, $B$, $C$.
Сначала вспомни сам · открыть ответ

Дано: общее уравнение прямой $Ax + By + C = 0$, где $A$ и $B$ одновременно не равны нулю. Вектор $\vec n = (A;B)$ — нормаль к прямой.

Идея: смотрим, какие коэффициенты равны нулю, и что это значит для положения прямой.

  • $C = 0$: $Ax + By = 0$ — точка $(0;0)$ удовлетворяет уравнению, прямая проходит через начало координат.
  • $A = 0$: $By + C = 0$, то есть $y = -\frac CB$ — прямая параллельна оси $Ox$ (нормаль $(0;B)$ вертикальна).
  • $B = 0$: $x = -\frac CA$ — прямая параллельна оси $Oy$.
  • $A = C = 0$: $y = 0$ — сама ось $Ox$.
  • $B = C = 0$: $x = 0$ — сама ось $Oy$.
  • $A, B, C \ne 0$: переносим $C$ и делим на $-C$: $$\frac{x}{-C/A} + \frac{y}{-C/B} = 1$$ Это уравнение в отрезках: прямая отсекает на осях $a = -\frac CA$ и $b = -\frac CB$.

Пример: $2x - 3y + 6 = 0$: все коэффициенты не нули, делим на $-6$: $\frac{x}{-3} + \frac y2 = 1$ — отрезки $-3$ и $2$.

Дано: $l_1:\ A_1x + B_1y + C_1 = 0$ и $l_2:\ A_2x + B_2y + C_2 = 0$, нормали $\vec n_1 = (A_1;B_1)$, $\vec n_2 = (A_2;B_2)$.

Идея: общие точки прямых — решения системы из двух уравнений. Сколько решений, так прямые и расположены.

  • Пересекаются (одно решение): $\frac{A_1}{A_2} \ne \frac{B_1}{B_2}$ — нормали не коллинеарны.
  • Параллельны (нет решений): $\frac{A_1}{A_2} = \frac{B_1}{B_2} \ne \frac{C_1}{C_2}$.
  • Совпадают (бесконечно много решений): $\frac{A_1}{A_2} = \frac{B_1}{B_2} = \frac{C_1}{C_2}$.

Угол между прямыми равен углу между нормалями:

$$\cos\varphi = \frac{|A_1A_2 + B_1B_2|}{\sqrt{A_1^2 + B_1^2}\,\sqrt{A_2^2 + B_2^2}}$$

Перпендикулярны ⇔ $A_1A_2 + B_1B_2 = 0$.

Пример: $2x - y + 3 = 0$ и $x - 3y + 1 = 0$: $\frac21 \ne \frac{-1}{-3}$ — пересекаются; $\cos\varphi = \frac{|2 + 3|}{\sqrt5\cdot\sqrt{10}} = \frac{1}{\sqrt2}$, $\varphi = 45^\circ$.
