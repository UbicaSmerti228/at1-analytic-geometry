  1. Определение — точная формулировка (что это за множество точек / что задаёт уравнение).
  2. Рисунок — с обозначениями всех элементов.
  3. Вывод уравнения — от определения к формуле, по шагам.
  4. Характеристики и частные случаи — все термины и формулы.
  5. Пример — одна короткая задача, показывающая, что ты умеешь применять.

1.Вывод уравнения прямой на плоскости, заданной двумя точками

Даны $M_1(x_1;y_1)$ и $M_2(x_2;y_2)$. Пусть $M(x;y)$ — произвольная точка прямой. Тогда векторы $\overline{M_1M} = (x - x_1;\, y - y_1)$ и $\overline{M_1M_2} = (x_2 - x_1;\, y_2 - y_1)$ коллинеарны, а у коллинеарных векторов координаты пропорциональны:

$$\frac{x - x_1}{x_2 - x_1} = \frac{y - y_1}{y_2 - y_1}$$

Если $x_2 = x_1$, прямая вертикальна: $x = x_1$ (аналогично для $y$). Пример и рисунок — задача 1 пробника.

2.Вывод уравнения прямой на плоскости, заданной точкой и направляющим вектором

Дано: $M_0(x_0;y_0)$ и $\vec s = (m;n) \ne \vec 0$, параллельный прямой. Точка $M(x;y)$ лежит на прямой ⇔ $\overline{M_0M} \parallel \vec s$ ⇔ координаты пропорциональны:

$$\frac{x - x_0}{m} = \frac{y - y_0}{n}$$

Это каноническое уравнение.

Обозначив общее значение отношений через $t$, получаем параметрические уравнения $x = x_0 + mt$, $y = y_0 + nt$, $t \in \mathbb R$. Ноль в знаменателе означает, что соответствующий числитель равен нулю.

3.Вывод уравнения прямой на плоскости, заданной точкой и нормальным вектором

Дано: $M_0(x_0;y_0)$ и $\vec n = (A;B) \ne \vec 0$, перпендикулярный прямой. Точка $M(x;y)$ лежит на прямой ⇔ $\overline{M_0M} \perp \vec n$ ⇔ $\vec n\cdot\overline{M_0M} = 0$:

$$A(x - x_0) + B(y - y_0) = 0$$

Раскрыв скобки и обозначив $C = -Ax_0 - By_0$, получаем общее уравнение $Ax + By + C = 0$. Вывод: в общем уравнении прямой коэффициенты при $x$ и $y$ — координаты нормального вектора. Рисунок — в модуле 1.

4.Вывод уравнения прямой с угловым коэффициентом и точкой

Угловой коэффициент $k = \operatorname{tg}\alpha$, где $\alpha$ — угол наклона прямой к положительному направлению $Ox$. Пусть прямая проходит через $M_0(x_0;y_0)$. Для любой другой её точки $M(x;y)$ из прямоугольного треугольника с катетами $x - x_0$ и $y - y_0$:

$$\operatorname{tg}\alpha = \frac{y - y_0}{x - x_0}\ \Rightarrow\ y - y_0 = k(x - x_0)$$

Если $M_0 = (0;b)$ — точка на оси $Oy$, получаем $y = kx + b$. Вертикальные прямые ($\alpha = 90^\circ$) углового коэффициента не имеют. Из общего уравнения $k = -\frac AB$.

5.Исследование общего уравнения прямой при различных значениях A, B, C

$Ax + By + C = 0$, где $A^2 + B^2 \ne 0$.

  • $C = 0$: $Ax + By = 0$ — прямая проходит через начало координат (точка $(0;0)$ удовлетворяет уравнению).
  • $A = 0$: $y = -\frac CB$ — параллельна $Ox$ (нормаль $(0;B)$ вертикальна).
  • $B = 0$: $x = -\frac CA$ — параллельна $Oy$.
  • $A = C = 0$: $y = 0$ — ось $Ox$; $\ B = C = 0$: $x = 0$ — ось $Oy$.
  • $A, B, C \ne 0$: делим на $-C$: $\frac{x}{-C/A} + \frac{y}{-C/B} = 1$ — уравнение в отрезках, $a = -\frac CA$, $b = -\frac CB$.

Все случаи можно посмотреть в интерактиве модуля 1.

6.Взаимное расположение двух прямых, заданных общими уравнениями

$l_1:\ A_1x + B_1y + C_1 = 0$, $\ l_2:\ A_2x + B_2y + C_2 = 0$. Общие точки — решения системы. Определитель системы $\Delta = A_1B_2 - A_2B_1$.

  • $\Delta \ne 0$, т.е. $\frac{A_1}{A_2} \ne \frac{B_1}{B_2}$: единственное решение — прямые пересекаются.
  • $\frac{A_1}{A_2} = \frac{B_1}{B_2} \ne \frac{C_1}{C_2}$: нормали коллинеарны, решений нет — параллельны.
  • $\frac{A_1}{A_2} = \frac{B_1}{B_2} = \frac{C_1}{C_2}$: уравнения равносильны — прямые совпадают.

Угол между прямыми — угол между нормалями: $\cos\varphi = \frac{|A_1A_2 + B_1B_2|}{\sqrt{A_1^2+B_1^2}\sqrt{A_2^2+B_2^2}}$. Перпендикулярность: $A_1A_2 + B_1B_2 = 0$. Пример — пример 1.5.

7.Взаимное расположение прямых на плоскости, заданных линейными уравнениями

Обычно здесь имеются в виду уравнения с угловым коэффициентом $y = kx + b$; для общих уравнений — вопрос 6.

$y = k_1x + b_1$, $y = k_2x + b_2$, $k_1 = \operatorname{tg}\alpha_1$, $k_2 = \operatorname{tg}\alpha_2$. Угол между прямыми $\varphi = \alpha_2 - \alpha_1$, по формуле тангенса разности:

$$\operatorname{tg}\varphi = \frac{\operatorname{tg}\alpha_2 - \operatorname{tg}\alpha_1}{1 + \operatorname{tg}\alpha_1\operatorname{tg}\alpha_2} = \frac{k_2 - k_1}{1 + k_1k_2}$$
  • Параллельны: $\varphi = 0 \Rightarrow k_1 = k_2$ (и $b_1 \ne b_2$; при $b_1 = b_2$ совпадают).
  • Перпендикулярны: $\varphi = 90^\circ$, тангенс не существует, знаменатель $1 + k_1k_2 = 0 \Rightarrow k_1k_2 = -1$.
  • Пересекаются: $k_1 \ne k_2$; точка — решение системы.

9.Гипербола. Определение. Терминология. Числовые характеристики

Определение. Гипербола — множество точек плоскости, модуль разности расстояний от которых до двух данных точек $F_1$, $F_2$ (фокусов) есть величина постоянная, равная $2a$, меньшая расстояния между фокусами $2c$.

Вывод. Оси выбираем так: $F_1(-c;0)$, $F_2(c;0)$. Для точки $M(x;y)$:

$$\left|\sqrt{(x+c)^2+y^2} - \sqrt{(x-c)^2+y^2}\right| = 2a$$

Переносим один корень вправо, возводим в квадрат и упрощаем:

$$\pm a\sqrt{(x-c)^2+y^2} = cx - a^2$$

Ещё раз возводим в квадрат:

$$\begin{gathered} a^2(x^2 - 2cx + c^2 + y^2) = \\ = c^2x^2 - 2a^2cx + a^4 \\ \Rightarrow\ (c^2 - a^2)x^2 - a^2y^2 = a^2(c^2 - a^2) \end{gathered}$$

Так как $c \gt a$, обозначим $b^2 = c^2 - a^2$ и разделим на $a^2b^2$:

$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$$

Характеристики: вершины $(\pm a;0)$; действительная ось $2a$, мнимая $2b$; основной прямоугольник $2a\times2b$; асимптоты $y = \pm\frac ba x$; фокусы $(\pm c;0)$, $c^2 = a^2 + b^2$; эксцентриситет $e = \frac ca \gt 1$; директрисы $x = \pm\frac ae$; фокальные радиусы $r_{1,2} = |ex \pm a|$; $\frac rd = e$. Сопряжённая гипербола $\frac{y^2}{b^2} - \frac{x^2}{a^2} = 1$, равносторонняя при $a = b$ ($e = \sqrt2$). Рисунки — модуль 2.3.

10.Парабола. Определение. Терминология. Числовые характеристики

Определение. Парабола — множество точек плоскости, равноудалённых от данной точки $F$ (фокуса) и данной прямой (директрисы), не проходящей через фокус.

Вывод. Пусть расстояние от фокуса до директрисы равно $p$. Ось $Ox$ проводим через фокус перпендикулярно директрисе, начало — посередине: $F\left(\frac p2;0\right)$, директриса $x = -\frac p2$. Для $M(x;y)$:

$$\sqrt{\left(x - \tfrac p2\right)^2 + y^2} = x + \tfrac p2 \ \Rightarrow\ x^2 - px + \tfrac{p^2}{4} + y^2 = x^2 + px + \tfrac{p^2}{4} \ \Rightarrow\ y^2 = 2px$$

Характеристики: $p$ — параметр; вершина $O(0;0)$; ось симметрии $Ox$; фокус $\left(\frac p2;0\right)$; директриса $x = -\frac p2$; фокальный радиус $r = x + \frac p2$; эксцентриситет $e = 1$. Другие положения: $y^2 = -2px$, $x^2 = \pm2py$. Рисунки — модуль 2.4.

11.Вывод уравнения плоскости, заданной тремя точками

Даны три точки $M_1, M_2, M_3$, не лежащие на одной прямой. Точка $M(x;y;z)$ лежит в их плоскости ⇔ векторы $\overline{M_1M}$, $\overline{M_1M_2}$, $\overline{M_1M_3}$ компланарны ⇔ их смешанное произведение равно нулю:

$$\begin{vmatrix} x - x_1 & y - y_1 & z - z_1 \\ x_2 - x_1 & y_2 - y_1 & z_2 - z_1 \\ x_3 - x_1 & y_3 - y_1 & z_3 - z_1 \end{vmatrix} = 0$$

Раскрыв определитель по первой строке, получаем $Ax + By + Cz + D = 0$. Пример — пример 3.3.

12.Вывод уравнения плоскости, заданной точкой и нормальным вектором

Дано: $M_0(x_0;y_0;z_0)$ и $\vec n = (A;B;C) \ne \vec 0$, перпендикулярный плоскости. $M(x;y;z)$ лежит в плоскости ⇔ $\overline{M_0M} \perp \vec n$ ⇔ $\vec n\cdot\overline{M_0M} = 0$:

$$A(x - x_0) + B(y - y_0) + C(z - z_0) = 0$$

Раскрыв скобки и обозначив $D = -Ax_0 - By_0 - Cz_0$, получаем общее уравнение $Ax + By + Cz + D = 0$. Расстояние от точки до плоскости: $d = \frac{|Ax_0 + By_0 + Cz_0 + D|}{\sqrt{A^2+B^2+C^2}}$.

13.Вывод уравнения прямой в пространстве, заданной двумя точками

Даны $M_1(x_1;y_1;z_1)$ и $M_2(x_2;y_2;z_2)$. Вектор $\overline{M_1M_2}$ — направляющий. Для точки $M$ прямой $\overline{M_1M} \parallel \overline{M_1M_2}$, значит:

$$\frac{x - x_1}{x_2 - x_1} = \frac{y - y_1}{y_2 - y_1} = \frac{z - z_1}{z_2 - z_1}$$
14.Вывод уравнения прямой в пространстве, заданной точкой и направляющим вектором

Дано: $M_0(x_0;y_0;z_0)$, $\vec s = (m;n;p) \ne \vec 0$. $M$ на прямой ⇔ $\overline{M_0M} \parallel \vec s$ ⇔ $\overline{M_0M} = t\vec s$:

$$\frac{x-x_0}{m} = \frac{y-y_0}{n} = \frac{z-z_0}{p}$$

или в параметрическом виде:

$$x = x_0 + mt,\ \ y = y_0 + nt,\ \ z = z_0 + pt$$
15.Общее уравнение прямой в пространстве. Переход к каноническому

Две непараллельные плоскости пересекаются по прямой, поэтому система $\begin{cases} A_1x + B_1y + C_1z + D_1 = 0 \\ A_2x + B_2y + C_2z + D_2 = 0 \end{cases}$ задаёт прямую — это общее уравнение.

Переход к каноническому: прямая лежит в обеих плоскостях, значит $\vec s \perp \vec n_1$ и $\vec s \perp \vec n_2$, откуда $\vec s = \vec n_1\times\vec n_2$. Точку находим, задав одну координату (например, $z = 0$) и решив систему из двух уравнений. Пример — задача 7 пробника.

16.Взаимное расположение плоскостей, заданных общими уравнениями

Угол между плоскостями равен углу между нормалями: $\cos\varphi = \frac{|A_1A_2 + B_1B_2 + C_1C_2|}{|\vec n_1|\,|\vec n_2|}$.

  • Параллельны: $\vec n_1 \parallel \vec n_2$, $\ \frac{A_1}{A_2} = \frac{B_1}{B_2} = \frac{C_1}{C_2} \ne \frac{D_1}{D_2}$.
  • Совпадают: все четыре отношения равны.
  • Перпендикулярны: $\vec n_1\cdot\vec n_2 = A_1A_2 + B_1B_2 + C_1C_2 = 0$.
  • Иначе пересекаются по прямой.
17.Взаимное расположение прямых в пространстве, заданных каноническими уравнениями

Прямые: $M_1$, $\vec s_1$ и $M_2$, $\vec s_2$. Угол: $\cos\varphi = \frac{|\vec s_1\cdot\vec s_2|}{|\vec s_1|\,|\vec s_2|}$.

  • $\vec s_1 \parallel \vec s_2$ — параллельны или совпадают (совпадают, если $M_1$ лежит на второй прямой).
  • $\vec s_1 \nparallel \vec s_2$ и $(\overline{M_1M_2}, \vec s_1, \vec s_2) = 0$ — лежат в одной плоскости, пересекаются.
  • $(\overline{M_1M_2}, \vec s_1, \vec s_2) \ne 0$ — скрещиваются.
  • Перпендикулярность: $\vec s_1\cdot\vec s_2 = 0$.

Пример — пример 5.2.

18.Взаимное расположение прямой (канонические уравнения) и плоскости (общее уравнение)

Прямая $\frac{x-x_0}{m} = \frac{y-y_0}{n} = \frac{z-z_0}{p}$, плоскость $Ax + By + Cz + D = 0$. Угол между прямой и плоскостью дополняет до $90^\circ$ угол между прямой и нормалью, поэтому:

$$\sin\varphi = \frac{|Am + Bn + Cp|}{\sqrt{A^2+B^2+C^2}\,\sqrt{m^2+n^2+p^2}}$$
  • Параллельны: $\vec s \perp \vec n$, т.е. $Am + Bn + Cp = 0$, и $M_0$ не в плоскости.
  • Прямая лежит в плоскости: $Am + Bn + Cp = 0$ и $Ax_0 + By_0 + Cz_0 + D = 0$.
  • Перпендикулярны: $\vec s \parallel \vec n$: $\frac Am = \frac Bn = \frac Cp$.

Рисунок — модуль 5.3, пример — задача 5 пробника.

19.Точка пересечения прямой с плоскостью

Записываем прямую параметрически: $x = x_0 + mt$, $y = y_0 + nt$, $z = z_0 + pt$, и подставляем в уравнение плоскости:

$$\begin{gathered} (Am + Bn + Cp)\,t \ + \\ + \ (Ax_0 + By_0 + Cz_0 + D) = 0 \end{gathered}$$
  • $Am + Bn + Cp \ne 0$: единственное $t$, подставляем его в параметрические уравнения — получаем точку.
  • $Am + Bn + Cp = 0$, свободный член $\ne 0$: решений нет — прямая параллельна плоскости.
  • Оба равны нулю: любое $t$ — прямая лежит в плоскости.

Пример — пример 5.3.

20.Цилиндрические поверхности

Определение. Цилиндрическая поверхность — поверхность, образованная движением прямой (образующей), которая остаётся параллельной заданному направлению и пересекает заданную линию (направляющую).

Уравнение. Пусть образующие параллельны $Oz$, а направляющая в плоскости $xOy$ задана уравнением $F(x,y) = 0$. Точка $M(x;y;z)$ лежит на поверхности ⇔ её проекция $(x;y;0)$ лежит на направляющей. Координата $z$ при этом любая, поэтому уравнение поверхности — то же $F(x,y) = 0$, без $z$.

Виды: эллиптический $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ (круговой при $a = b$), гиперболический $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$, параболический $y^2 = 2px$. Посмотреть их в 3D — модуль 6.

10Эллипс. Определение. Терминология. Числовые характеристики.6 б.

Образцовый развёрнутый ответ — так его и стоит писать на АТ.

1. Определение. Эллипсом называется множество всех точек плоскости, сумма расстояний от каждой из которых до двух данных точек $F_1$ и $F_2$, называемых фокусами, есть величина постоянная, равная $2a$, большая, чем расстояние между фокусами $2c$: $\ r_1 + r_2 = 2a$, $a \gt c$.

2. Рисунок — см. модуль 2.2: фокусы, вершины, полуоси, директрисы, фокальные радиусы.

3. Вывод канонического уравнения. Ось $Ox$ проведём через фокусы, начало — посередине между ними: $F_1(-c;0)$, $F_2(c;0)$. Для точки $M(x;y)$ эллипса:

$$\sqrt{(x+c)^2 + y^2} + \sqrt{(x-c)^2 + y^2} = 2a$$

Переносим второй корень вправо и возводим в квадрат:

$$\begin{gathered} (x+c)^2 + y^2 = \\ = 4a^2 - 4a\sqrt{(x-c)^2 + y^2} + (x-c)^2 + y^2 \\ \Rightarrow\ a\sqrt{(x-c)^2 + y^2} = a^2 - cx \end{gathered}$$

Ещё раз возводим в квадрат:

$$\begin{gathered} a^2x^2 - 2a^2cx + a^2c^2 + a^2y^2 = \\ = a^4 - 2a^2cx + c^2x^2 \\ \Rightarrow\ (a^2 - c^2)x^2 + a^2y^2 = a^2(a^2 - c^2) \end{gathered}$$

Так как $a \gt c$, обозначим $b^2 = a^2 - c^2$ и разделим на $a^2b^2$:

$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$$

Это каноническое уравнение эллипса.

4. Терминология и числовые характеристики.

  • Оси координат — оси симметрии, начало — центр симметрии эллипса.
  • Вершины: $A_1(-a;0)$, $A_2(a;0)$, $B_1(0;-b)$, $B_2(0;b)$.
  • $2a$ — большая ось, $2b$ — малая ось; $a$ и $b$ — большая и малая полуоси.
  • $2c$ — фокусное расстояние, $c = \sqrt{a^2 - b^2}$.
  • Эксцентриситет $e = \frac ca$, $0 \le e \lt 1$. Характеризует вытянутость: $e = 0$ — окружность ($a = b$), чем ближе $e$ к 1, тем эллипс более сплюснут, так как $\frac ba = \sqrt{1 - e^2}$.
  • Фокальные радиусы точки $M(x;y)$: $r_1 = a + ex$, $r_2 = a - ex$.
  • Директрисы: $x = \pm\frac ae$. Для любой точки эллипса отношение расстояния до фокуса к расстоянию до соответствующей директрисы равно $e$.
  • Параметрические уравнения: $x = a\cos t$, $y = b\sin t$.
  • Если $b \gt a$, фокусы лежат на оси $Oy$: $c^2 = b^2 - a^2$, $e = \frac cb$.

5. Пример. $\frac{x^2}{25} + \frac{y^2}{9} = 1$: $a = 5$, $b = 3$, $c = 4$, $e = 0{,}8$, фокусы $(\pm4;0)$, директрисы $x = \pm\frac{25}{4}$.

Типичные ошибки — проверь себя по списку

  1. Вектор считают «начало минус конец». Правильно: конец минус начало.
  2. Теряют минус при подстановке отрицательных координат: $x - (-3) = x + 3$.
  3. Для угла между прямой и плоскостью берут $\cos$ вместо $\sin$.
  4. Путают векторы: в общем уравнении стоит нормаль $\vec n$, в знаменателях канонического — направляющий $\vec s$.
  5. Путают формулы для $c$: эллипс $c^2 = a^2 - b^2$, гипербола $c^2 = a^2 + b^2$.
  6. Эксцентриситет «не того размера»: у эллипса $e \lt 1$, у параболы $e = 1$, у гиперболы $e \gt 1$. Если вышло иначе — ищи ошибку.
  7. При выделении квадрата не умножают «хвост» на вынесенный коэффициент: $4(x^2 - 2x) = 4(x-1)^2 - 4$.
  8. Неверно читают центр: $(x+1)^2$ означает $x_0 = -1$.
  9. Не доводят до единицы справа. Если справа после деления $-1$, это сопряжённая гипербола (или пустое множество для «эллипса»).
  10. В векторном произведении забывают минус у $\vec j$.
  11. Пугаются нуля в знаменателе канонического уравнения — это нормально, он означает, что числитель равен нулю.
  12. Не делают проверку. Подставь точку в полученное уравнение — 20 секунд, и ошибка поймана.
