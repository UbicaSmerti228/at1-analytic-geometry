№5Плоскость через точку 2 б.

Алгоритм
  1. Найди нормаль $\vec n = (A;B;C)$:
    • плоскость ⟂ прямой → $\vec n$ = направляющий прямой (знаменатели или числа при $t$);
    • плоскость ∥ плоскости → $\vec n$ та же (коэффициенты при $x, y, z$);
    • через три точки → $\vec n = \overline{M_1M_2}\times\overline{M_1M_3}$.
  2. Подставь в формулу и раскрой скобки: $$A(x - x_0) + B(y - y_0) + C(z - z_0) = 0$$
  3. Проверка: подставь точку — должно получиться 0.

Ловушки: знак свободного члена; в скобках координаты данной точки, а не точки прямой.

Объяснение на пальцах

Плоскость — как лист бумаги. Чтобы его задать, нужны две вещи: точка, через которую он проходит, и палочка, которая торчит из листа строго перпендикулярно. Эта палочка — нормаль $\vec n = (A;B;C)$.

Если сказано «перпендикулярно прямой» — прямая и есть палочка. Её направление — числа в знаменателях. Числа из числителей прямой не нужны вообще.

Пример целиком. Точка $M(1;2;3)$, прямая $\frac{x-5}{2} = \frac{y+1}{-1} = \frac{z}{4}$.

  1. Палочка — знаменатели: $\vec n = (2;-1;4)$.
  2. Шаблон «палочка × (буква минус координата точки)»: $2(x-1) - 1(y-2) + 4(z-3) = 0$.
  3. Раскрываем скобки: $2x - 2 - y + 2 + 4z - 12 = 0$, то есть $2x - y + 4z - 12 = 0$.
  4. Проверка — подставь точку: $2 - 2 + 12 - 12 = 0$ ✓

№9Поверхность 4 б.

Алгоритм
  1. Какой переменной нет в уравнении? → это цилиндр, образующие ∥ оси этой переменной.
  2. Название — по кривой из уравнения:
    • $u^2 + v^2 = R^2$ → круговой цилиндр;
    • $\frac{u^2}{a^2} + \frac{v^2}{b^2} = 1$ → эллиптический;
    • $u^2 - v^2 = 1$ → гиперболический;
    • $u = c\,v^2$ → параболический.
  3. Сечения: подставь по очереди $x = 0$, $y = 0$, $z = 0$. Получится кривая, две прямые ($v = \pm2$), одна прямая ($v = 0$) или «нет пересечения» ($-v^2 = 1$).

Плоскости: $x = 0$ — это $yOz$, $y = 0$ — $xOz$, $z = 0$ — $xOy$.

Объяснение на пальцах

Цилиндр — это труба. Если в уравнении нет какой-то буквы, например $z$, значит $z$ может быть каким угодно. Кривая из уравнения «протягивается» вдоль оси $Oz$ — получается труба.

  1. Какой буквы нет? Вдоль этой оси идут образующие (линии трубы).
  2. Как называется? Смотри на оставшееся: $x^2 + y^2 = 4$ — круг, значит круговой; плюс и разные числа — эллиптический; минус между квадратами — гиперболический; одна буква без квадрата ($x = y^2$) — параболический.
  3. Сечения. «Сечение плоскостью $x = 0$» значит: поставь 0 вместо $x$ и посмотри, что осталось.
    • осталась та же кривая — называешь её;
    • вышло $y^2 = 4$, то есть $y = \pm2$ — две прямые;
    • вышло $y^2 = 0$, то есть $y = 0$ — одна прямая;
    • вышло $-y^2 = 1$ (квадрат не бывает отрицательным) — нет пересечения.

Пример: $z^2 - y^2 = 1$. Нет $x$ — труба вдоль $Ox$. Минус — гиперболический цилиндр. $x = 0$: гипербола. $y = 0$: $z^2 = 1$, две прямые. $z = 0$: $-y^2 = 1$, нет пересечения.

№2Кривая по числам 2 б.

Формулы
  • Эллипс: $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$, $\ c^2 = a^2 - b^2$.
  • Гипербола: $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$, $\ c^2 = a^2 + b^2$, асимптоты $y = \pm\frac ba x$.
  • Эксцентриситет $e = \frac ca$ (у эллипса меньше 1, у гиперболы больше 1), отсюда $c = e\cdot a$.
  • Фокусы $(\pm c;\,0)$. Если больший знаменатель под $y^2$ — фокусы $(0;\,\pm c)$.
  • Парабола $y^2 = 2px$: фокус $\left(\frac p2;0\right)$, директриса $x = -\frac p2$.

Ловушки: «оси $2a$ и $2b$» — сначала раздели на 2; уравнение вида $9x^2 + 25y^2 = 225$ сначала раздели на 225.

Объяснение на пальцах

Эллипс — сплюснутый круг. Гипербола — две отдельные «ветки». У обеих есть числа $a$, $b$, $c$: $a$ и $b$ — полуоси (половины осей), $c$ — расстояние от центра до фокуса.

  • Уравнение: в знаменателях квадраты полуосей: $\frac{x^2}{a^2} \pm \frac{y^2}{b^2} = 1$. Плюс — эллипс, минус — гипербола.
  • Связь: у эллипса $c^2 = a^2 - b^2$, у гиперболы $c^2 = a^2 + b^2$.
  • Эксцентриситет $e = \frac ca$. Значит, $c = e\cdot a$.

Пример 1. Гипербола, оси $2a = 10$, $2b = 8$. Делим на 2: $a = 5$, $b = 4$. Ответ: $\frac{x^2}{25} - \frac{y^2}{16} = 1$.

Пример 2. Фокусы эллипса $9x^2 + 25y^2 = 225$. Делим всё на 225: $\frac{x^2}{25} + \frac{y^2}{9} = 1$, $a = 5$, $b = 3$. $c^2 = 25 - 9 = 16$, $c = 4$. Ответ: $F(\pm4;\,0)$.

№4Прямая в пространстве 2 б.

Что нужно знать
  • Каноническое: $\frac{x - x_0}{m} = \frac{y - y_0}{n} = \frac{z - z_0}{p}$; параметрическое: $x = x_0 + mt$, $y = y_0 + nt$, $z = z_0 + pt$.
  • Через две точки → $\vec s = \overline{AB}$ (конец минус начало).
  • ∥ прямой → тот же $\vec s$; ⟂ плоскости → $\vec s = \vec n$; ∥ оси $Ox$ → $\vec s = (1;0;0)$.
  • Ноль в знаменателе — нормально: эта координата не меняется.
Объяснение на пальцах

Прямая в пространстве = точка + направление. Направление — вектор $\vec s = (m;n;p)$, «куда смотрит» прямая.

  • Через две точки: $\vec s = B - A$ — из второй точки вычитаешь первую, по каждой координате.
  • Каноническое: $\frac{x - x_0}{m} = \frac{y - y_0}{n} = \frac{z - z_0}{p}$ — сверху «буква минус координата точки», снизу направление.
  • Параметрическое: $x = x_0 + mt$, $y = y_0 + nt$, $z = z_0 + pt$.

Пример. $A(2;5;1)$, $B(3;2;1)$. $\vec s = (3-2;\ 2-5;\ 1-1) = (1;-3;0)$. Ответ: $\frac{x-2}{1} = \frac{y-5}{-3} = \frac{z-1}{0}$.

Знаки: если координата точки $-2$, в числителе будет $x + 2$. Ноль в знаменателе — это нормально, не пугайся.

№10Теория: выводы уравнения прямой 4 б.

Номер вопроса обычно совпадает с номером варианта. Выучи шпаргалку ниже, потом отвечай на вопросы тренажёра. На контрольной пиши: дано → рисунок → идея → вывод → формула в рамке → пример.

1. Через две точки

Для любой точки $M(x;y)$ прямой векторы $\overline{M_1M} = (x - x_1;\ y - y_1)$ и $\overline{M_1M_2} = (x_2 - x_1;\ y_2 - y_1)$ коллинеарны → координаты пропорциональны:

$$\frac{x - x_1}{x_2 - x_1} = \frac{y - y_1}{y_2 - y_1}$$
2. Через точку и направляющий вектор

$\vec s = (m;n)$ ∥ прямой. Для точки $M$ прямой $\overline{M_0M} \parallel \vec s$ → координаты пропорциональны:

$$\frac{x - x_0}{m} = \frac{y - y_0}{n}$$

Приравняв к $t$: $x = x_0 + mt$, $y = y_0 + nt$.

3. Через точку и нормальный вектор

$\vec n = (A;B)$ ⟂ прямой. $\overline{M_0M} \perp \vec n$ → скалярное произведение равно 0:

$$A(x - x_0) + B(y - y_0) = 0$$

Раскрыв скобки: $Ax + By + C = 0$, где $C = -Ax_0 - By_0$. Коэффициенты при $x$ и $y$ — нормаль.

4. Угловой коэффициент и точка

$k = \operatorname{tg}\alpha$. Прямоугольный треугольник с катетами $x - x_0$ и $y - y_0$, угол при $M_0$ равен $\alpha$:

$$\operatorname{tg}\alpha = \frac{y - y_0}{x - x_0}\ \Rightarrow\ y - y_0 = k(x - x_0)$$

При $M_0 = (0;b)$: $y = kx + b$. У вертикальной прямой $k$ нет ($\operatorname{tg}90^\circ$ не существует).

5. Исследование общего уравнения

$Ax + By + C = 0$: при $C = 0$ — через начало координат; $A = 0$ — ∥ $Ox$; $B = 0$ — ∥ $Oy$; $A = C = 0$ — ось $Ox$; $B = C = 0$ — ось $Oy$; все ≠ 0 — делим на $-C$: $\frac{x}{a} + \frac{y}{b} = 1$, $a = -\frac CA$, $b = -\frac CB$.

6. Взаимное расположение двух прямых

Пересекаются: $\frac{A_1}{A_2} \ne \frac{B_1}{B_2}$. Параллельны: $\frac{A_1}{A_2} = \frac{B_1}{B_2} \ne \frac{C_1}{C_2}$. Совпадают: все три отношения равны. Перпендикулярны: $A_1A_2 + B_1B_2 = 0$. Угол:

$$\cos\varphi = \frac{|A_1A_2 + B_1B_2|}{\sqrt{A_1^2 + B_1^2}\,\sqrt{A_2^2 + B_2^2}}$$
Объяснение на пальцах

Любой вывод пишется по одному шаблону: «Дано» → рисунок → «возьмём любую точку M(x; y) на прямой» → условие → формула в рамке. Меняется только условие:

  • Две точки: векторы $\overline{M_1M}$ и $\overline{M_1M_2}$ лежат на одной прямой — их координаты пропорциональны.
  • Точка и направляющий $\vec s$: $\overline{M_0M}$ параллелен $\vec s$ — координаты пропорциональны.
  • Точка и нормаль $\vec n$: $\overline{M_0M}$ перпендикулярен $\vec n$ — скалярное произведение равно 0.
  • Угловой коэффициент: в прямоугольном треугольнике $\operatorname{tg}\alpha$ = противолежащий катет / прилежащий.

Выучи эти 4 строчки — и любой вывод восстановишь сам.

№8Построить кривую 4 б.

Алгоритм
  1. Тип: при $x^2$ и $y^2$ одинаковые знаки — эллипс, разные — гипербола, в квадрате одна переменная — парабола.
  2. Сгруппируй и вынеси коэффициент: $4x^2 - 8x = 4(x^2 - 2x)$.
  3. Полный квадрат: $x^2 - 2x = (x - 1)^2 - 1$, значит $4(x^2 - 2x) = 4(x-1)^2 - 4$.
  4. Числа вправо, раздели на правую часть — справа 1.
  5. Центр — числа из скобок с обратным знаком. Рисунок: центр → полуоси → вершины → кривая.

Ловушки: умножить «хвост» на вынесенное число; знак центра: $(x + 2)^2$ значит $x_0 = -2$.

Объяснение на пальцах

Цель: превратить длинное уравнение в «красивое»: $\frac{(x-h)^2}{\dots} + \frac{(y-k)^2}{\dots} = 1$. Из него сразу видно центр и размеры.

Полный квадрат: $x^2 - 6x$ → берёшь половину от 6, это 3 → $(x-3)^2 - 9$ (вычитаешь $3^2$, потому что лишнее добавилось).

Пример целиком: $x^2 + 4x + 4y^2 = 0$.

  1. $x^2 + 4x = (x+2)^2 - 4$, получаем $(x+2)^2 - 4 + 4y^2 = 0$.
  2. Число вправо: $(x+2)^2 + 4y^2 = 4$.
  3. Делим на 4: $\frac{(x+2)^2}{4} + \frac{y^2}{1} = 1$.
  4. Центр — числа из скобок с обратным знаком: $(-2;\,0)$. Полуоси: $\sqrt4 = 2$ по $x$, $\sqrt1 = 1$ по $y$.
  5. Рисуем: точка-центр, от неё на 2 влево и вправо, на 1 вверх и вниз, обводим овал.

Если перед $x^2$ число ($2x^2 - 8x$): вынеси его, $2(x^2 - 4x) = 2[(x-2)^2 - 4] = 2(x-2)^2 - 8$. «Хвост» $-4$ тоже умножается на 2!

№1Прямая на плоскости 2 б.

Что нужно знать
  • $k = \operatorname{tg}\alpha$: $\operatorname{tg}30^\circ = \frac{\sqrt3}{3}$, $\operatorname{tg}45^\circ = 1$, $\operatorname{tg}60^\circ = \sqrt3$. Если $k \lt 0$ — угол тупой: $180^\circ$ минус острый.
  • Через две точки: $\frac{x - x_1}{x_2 - x_1} = \frac{y - y_1}{y_2 - y_1}$, затем «крест-накрест».
  • ∥ данной прямой $Ax + By + C = 0$ — та же нормаль $(A;B)$; ⟂ — нормаль $(B;-A)$.
  • Параметр: ⟂ ⇔ $A_1A_2 + B_1B_2 = 0$; ∥ ⇔ $\frac{A_1}{A_2} = \frac{B_1}{B_2}$.
Объяснение на пальцах

Прямая $Ax + By + C = 0$: пара $(A;B)$ — «палочка», перпендикулярная прямой. В виде $y = kx + b$ число $k$ — наклон: $k = \operatorname{tg}\alpha$.

  • Угол: $\operatorname{tg}45^\circ = 1$, $\operatorname{tg}60^\circ = \sqrt3$, $\operatorname{tg}30^\circ = \frac{\sqrt3}{3}$. Если $k$ с минусом — угол $180^\circ$ минус этот.
  • Через две точки: формула, потом «крест-накрест» (умножаешь накрест).
  • Параллельно: те же $A$ и $B$, новое $C$ — его находишь подстановкой точки.
  • Перпендикулярно: поменяй $A$ и $B$ местами и у одного смени знак.

Пример. Через $M(2;3)$ параллельно $2x - y + 6 = 0$. Пишем $2x - y + C = 0$, подставляем $M$: $4 - 3 + C = 0$, $C = -1$. Ответ: $2x - y - 1 = 0$.

№3Плоскость 2 б.

Что нужно знать
  • Плоскости ⟂ ⇔ $\vec n_1\cdot\vec n_2 = A_1A_2 + B_1B_2 + C_1C_2 = 0$; ∥ ⇔ нормали пропорциональны.
  • Расстояние: $d = \dfrac{|Ax_0 + By_0 + Cz_0 + D|}{\sqrt{A^2 + B^2 + C^2}}$.
  • Точки, равноудалённые от $P$ и $Q$: плоскость через середину $PQ$ с нормалью $\overline{PQ}$.
  • Нет переменной → плоскость ∥ этой оси; нет двух → ∥ координатной плоскости; $D = 0$ → через начало.
Объяснение на пальцах

Плоскость $Ax + By + Cz + D = 0$: тройка $(A;B;C)$ — нормаль.

  • Перпендикулярны: перемножь соответствующие числа и сложи — должно быть 0: $A_1A_2 + B_1B_2 + C_1C_2 = 0$.
  • Параллельны: числа второй плоскости в одно и то же число раз больше, чем у первой.
  • Расстояние от точки: подставь точку в левую часть, возьми модуль, раздели на $\sqrt{A^2 + B^2 + C^2}$.

Пример. При каком $A$ перпендикулярны $5x + y - 3z - 3 = 0$ и $2x + Ay + 3z + 1 = 0$? $5\cdot2 + 1\cdot A + (-3)\cdot3 = 0$, то есть $10 + A - 9 = 0$, $A = -1$.

№6Плоскость, уровень B 4 б.

Инструменты
  • Середина: $\left(\frac{x_1+x_2}{2};\ \frac{y_1+y_2}{2}\right)$. Точка пересечения медиан: $\left(\frac{x_A+x_B+x_C}{3};\ \frac{y_A+y_B+y_C}{3}\right)$.
  • Угол между прямыми: $\operatorname{tg}\varphi = \left|\dfrac{k_2 - k_1}{1 + k_1k_2}\right|$.
  • Высота из $C$ ⟂ $AB$ → вектор $\overline{AB}$ — её нормаль. Длина высоты — расстояние от $C$ до прямой $AB$.
  • Симметричная точка: $M' = 2H - M$, где $H$ — проекция.
Объяснение на пальцах

№6 — это не новая теория, а сборка из кубиков №1. Каждая задача — 2–3 простых шага подряд. Главное — понять, из каких кубиков она собрана:

  • «Найти третью вершину по точке пересечения медиан» — один шаг. Точка пересечения медиан — среднее трёх вершин, значит $x_C = 3x_O - x_A - x_B$. Пример: $A(2;2)$, $B(3;0)$, $O(3;1)$: $x_C = 9 - 2 - 3 = 4$, $y_C = 3 - 2 - 0 = 1$.
  • «Угол между стороной и медианой» — кубики: середина → два угловых коэффициента $k = \frac{\Delta y}{\Delta x}$ → формула $\operatorname{tg}\varphi$.
  • «Прямая под углом 45° к данной» — $\left|\frac{k - k_1}{1 + k_1k}\right| = 1$. Модуль раскрывается двумя способами, поэтому ответов два.
  • «Уравнение высоты» — высота ⟂ стороне, поэтому вектор стороны — её нормаль. Дальше «точка + нормаль».
  • «Симметричная точка» — опускаешь перпендикуляр (прямая через точку по нормали данной прямой), находишь основание $H$, потом $M' = 2H - M$ (точка «перепрыгивает» через прямую на такое же расстояние).
  • «Через точку пересечения ⟂ прямой» — решаешь систему двух уравнений (точка), потом «перпендикулярно»: нормаль $(A;B)$ меняешь на $(B;-A)$.

№7Пространство, уровень B 4 б.

Инструменты
  • Прямая через точку $P$ по нормали плоскости: $x = x_P + At$, $y = y_P + Bt$, $z = z_P + Ct$.
  • Подставить параметрическую прямую в уравнение плоскости → найти $t$ → найти точку.
  • Прямая из двух плоскостей: $\vec s = \vec n_1 \times \vec n_2$, точка — положить $y = 0$ (или $z = 0$) и решить систему.
  • Проекция на прямую: точка $M(t)$ прямой, условие $\overline{PM}\cdot\vec s = 0$.
Объяснение на пальцах

Почти весь №7 держится на одном трюке: «запусти прямую и найди, где она попадёт в плоскость».

  1. Записываешь прямую в параметрическом виде: каждая координата $= $ число $+$ число$\cdot t$.
  2. Подставляешь $x$, $y$, $z$ в уравнение плоскости — получается простое уравнение на $t$.
  3. Находишь $t$ и подставляешь обратно — это и есть точка.

Пример (проекция точки на плоскость): $A(2;3;1)$, плоскость $x - y + z + 3 = 0$. Нормаль $(1;-1;1)$, прямая $x = 2 + t$, $y = 3 - t$, $z = 1 + t$. Подставляем: $(2+t) - (3-t) + (1+t) + 3 = 0$, $3t + 3 = 0$, $t = -1$. Точка $(1;4;0)$.

  • Точка пересечения прямой и плоскости — тот же трюк, только прямая уже дана.
  • Симметричная точка — сначала проекция $H$, потом $P' = 2H - P$.
  • Каноническое из двух плоскостей — направление: векторное произведение нормалей (определитель с $\vec i, \vec j, \vec k$, у $\vec j$ минус); точка: $y = 0$ и система из двух уравнений.
  • Проекция на прямую — берёшь точку прямой с $t$, строишь вектор от $P$ к ней и требуешь, чтобы он был перпендикулярен прямой: скалярное произведение с $\vec s$ равно 0.
